Здравствуйте, Олег!

Нам необходимо разработать интернет-ресурс для фанатского сервера одной известной MMORPG — что-то вроде доски объявлений. Пользователи нашего ресурса должны иметь возможность зарегистрироваться в нём по e-mail, получив письмо с кодом подтверждения регистрации. После регистрации им становится доступно создание и редактирование объявлений. Объявления состоят из заголовка и текста, внутри которого могут быть картинки, встроенные видео и другой контент. Пользователи могут отправлять отклики на объявления других пользователей, состоящие из простого текста. При отправке отклика пользователь должен получить e-mail с оповещением о нём. Также пользователю должна быть доступна приватная страница с откликами на его объявления, внутри которой он может фильтровать отклики по объявлениям, удалять их и принимать (при принятии отклика пользователю, оставившему отклик, также должно прийти уведомление). Кроме того, пользователь обязательно должен определить объявление в одну из следующих категорий: Танки, Хилы, ДД, Торговцы, Гилдмастеры, Квестгиверы, Кузнецы, Кожевники, Зельевары, Мастера заклинаний.

Также мы бы хотели иметь возможность отправлять пользователям новостные рассылки.

Доска объявлений для MMORPG-сообщества

Описание проекта

Данный проект представляет собой специализированную платформу для размещения объявлений, разработанную специально для фанатского сервера MMORPG. Платформа позволяет игрокам находить команду, обмениваться внутриигровыми предметами и предлагать услуги в рамках игрового мира через удобный и интуитивно понятный веб-интерфейс.

Основная функциональность

Система регистрации и авторизации

  • Регистрация пользователей с подтверждением по email
  • Генерация уникальных 5-значных кодов верификации с ограниченным сроком действия (10 минут)
  • Безопасное хранение пользовательских данных

Управление объявлениями

  • Создание и редактирование объявлений с поддержкой rich-text формата (CKEditor5)
  • Встраивание изображений, видео и таблиц в объявления
  • Категоризация объявлений (Танки, Хилы, ДД, Торговцы, Гилдмастеры, Квестгиверы, Кузнецы, Кожевники, Зельевары, Мастера заклинаний)
  • Полноценная система управления статусом объявлений

Система откликов

  • Возможность откликаться на объявления других пользователей
  • Получение уведомлений о новых откликах по email
  • Приватная страница администрирования полученных откликов
  • Фильтрация откликов по объявлениям, с функциями удаления и принятия
  • Email-уведомления авторов откликов о принятии их предложений

Информационная рассылка

  • Еженедельные автоматические рассылки о новых объявлениях
  • Возможность подписки/отписки от рассылок
  • Простой и интуитивно понятный интерфейс управления подписками

Инфраструктура сайта

  • Информационные статические страницы (О нас, Контакты)
  • Адаптивный дизайн для комфортного использования на различных устройствах
  • Интуитивно понятная навигация

Технические решения

Архитектура проекта

  • Построен на фреймворке Django 5.2 с использованием паттерна MVC
  • Модульная структура с разделением на приложения (post, response, category, author)
  • Использование встроенной системы шаблонов Django для представления данных

Система моделей данных

  • Расширенная модель пользователя (Author) с привязкой к стандартной Django-модели User
  • Эффективная структура хранения с корректными связями между моделями
  • Оптимизация БД с использованием индексов для частых запросов

Асинхронные задачи

  • Использование Celery для обработки тяжелых задач и рассылок
  • Redis в качестве брокера сообщений для Celery
  • Периодические задачи по расписанию через django-celery-beat

Безопасность

  • Защита от CSRF-атак через встроенные механизмы Django
  • Безопасное хранение паролей с хешированием
  • Проверка прав доступа к контенту

Email-интеграция

  • Настроена отправка писем через SMTP (Яндекс.Почта)
  • Система шаблонов для HTML-писем с разметкой
  • Обработка ошибок и логирование при отправке уведомлений

Расширяемость

  • Тщательно спроектированная структура БД, позволяющая легко добавлять новые функции
  • Покрытие тестами критически важных компонентов системы
  • Логирование ошибок для быстрого выявления проблем

Перспективы развития

Проект имеет большой потенциал для расширения функциональности:

  • Внедрение системы платных объявлений с приоритетным отображением
  • Добавление интеграции с популярными игровыми сервисами через API
  • Реализация внутренней системы сообщений между пользователями
  • Развитие социальных функций для построения сообщества
  • Интеграция с Discord для мгновенных уведомлений

Тестирование

Проект включает комплексную систему тестирования:

  • Unit-тесты для ключевых функций и моделей
  • Интеграционные тесты для проверки взаимодействия компонентов
  • Тесты на отправку email-уведомлений с использованием моков
  • Тесты функций подписки/отписки от рассылок

Платформа разработана с учетом потребностей игрового сообщества и предоставляет все необходимые инструменты для эффективного взаимодействия игроков вне игрового мира.
